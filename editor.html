Recommended · A complete page

  1. Download index.html. It's the whole tag page with your design built in.
  2. Replace the old index.html in your folder or repository with it, and keep editor.html next to it.
  3. Upload it to wherever you host the page (any web host works). Use the same web address as before, or tags you've already written will point to the old page.

To keep editing later, open editor.html from the same folder. It picks up the design saved in index.html.

Or · Just the design file

config.json goes next to index.html. It's only used when index.html has no design built in, and it doesn't load when the page is opened as a local file.
